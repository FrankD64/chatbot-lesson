Key Words

Every coding word used in these lessons, in plain language, with an example.

Key words, in the order you meet them
WordWhat it meansExample
CodeInstructions written for a computer. The computer follows them in order, exactly as written.Every line in a Python box is code.
PythonA language for writing code. It’s used for games, websites, science and more.Everything in these lessons is Python.
RunTo tell the computer to follow your code.Press ▶ Run.
OutputWhat your program shows on the screen.Hello, world!
print()An instruction that shows a message on the screen.print("Hello, world!")
StringText inside quotes. The quotes show where the text starts and ends."I like pizza"
ErrorA message from Python saying it can’t follow a line of your code. It tells you which line to check.SyntaxError: '(' was never closed
BugA mistake in code. Fixing it is called debugging.Print("Hi") has a bug: the capital P.
input()An instruction that asks a question and waits for the user to type an answer.input("What is your name? ")
VariableA labelled box that stores information, like an answer, so you can use it later.name = input("What is your name? ")
= (equals sign)Puts something into a variable. Read it as “store this in.”food = "tacos"
+ (plus sign)Joins pieces of text into one message."Hi " + name
CommentA note for people, starting with #. Python skips it.# This line asks for a name
ChatbotA program that talks with you by asking questions and replying.What you build in Lesson 2.
