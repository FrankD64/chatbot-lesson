Find the error message you got. Each one says what it means and how to fix it.

A quote is missing

SyntaxError: unterminated string literal

Your text has a quote at the start but not at the end (or the other way around). Put a quote on both sides.

print("Hello)

print("Hello")

A bracket is missing or extra

SyntaxError: '(' was never closed

SyntaxError: unmatched ')'

Every ( needs exactly one ). Count them, then add or delete one.

print("I like pizza"

print("I like pizza")

A capital letter in print or input

NameError: name 'Print' is not defined. Did you mean: 'print'?

Python treats Print and print as different words. Use small letters.

Print("Coding is fun!")

print("Coding is fun!")

Python doesn’t know a word

NameError: name 'Hello' is not defined

Usually one of these:

  • Text is missing its quotes, so Python reads it as an instruction.
  • A variable is spelled differently from when you made it (nme instead of name).
  • A variable is used before the line that makes it.

print(Hello)

print("Hello")

Curly quotes

SyntaxError: invalid character '“' (U+201C)

Python only reads straight quotes ("). Curly quotes usually come from copying code out of a document. Retype them with the quote key, or use the “Fix them for me” button in the Python box.

Something is out of place

SyntaxError: invalid syntax. Perhaps you forgot a comma?

Python can’t tell how the line fits together. Often a + is missing between two pieces you’re joining.

print("Hi " name)

print("Hi " + name)

Joining text with a number

TypeError: can only concatenate str (not "int") to str

You used + to join text with a number that isn’t in quotes. Put the number inside the quotes.

print("I am " + 12)

print("I am 12")

An extra space at the start

IndentationError: unexpected indent

There are spaces before the code on that line. Delete them so the line starts at the left edge.

No error, but the output looks wrong

Output says HiSam: add a space inside the quotes.

print("Hi" + name)

print("Hi " + name)

Output says name instead of the answer: take the quotes off the variable.

print("name")

print(name)
