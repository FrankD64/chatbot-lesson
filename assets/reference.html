A guide on how to fix the errors you will be getting. Each one gives the error text and how to fix them.

A quote is missing

SyntaxError: unterminated string literal

Your text has a quote at the start but not at the end or the other way around. Put a quote on both sides of the text.

print("Hello)

print("Hello")

A bracket is missing

SyntaxError: '(' was never closed

SyntaxError: unmatched ')'

Your function has a bracket at the start but not at the end or the other way around. Put a bracket on both sides.

print("I like pizza"

print("I like pizza")

Capitalization error

NameError: name 'Print' is not defined. Did you mean: 'print'?

Python treats Print and print as different words, so use uncapitalized letters.

Print("Coding is fun!")

print("Coding is fun!")

Python doesn’t know a word

NameError: name 'Hello' is not defined

It can be any of these:

  • Text is missing its quotes so Python reads it as an instruction.
  • A variable is spelled differently from when you made it. For example, nme instead of name.
  • A variable is being used before the line that makes the variable is ran.

print(Hello)

print("Hello")

Curly quotes

SyntaxError: invalid character '“' (U+201C)

Python only reads straight quotes. Curly quotes and more characters like these usually come from copying code. Retype them with the correct keys on your keyboard.

Something is out of place

SyntaxError: invalid syntax. Perhaps you forgot a comma?

Python can’t understand how the line fits together. In your case, it is often a + missing between two pieces you’re combining together.

print("Hi " name)

print("Hi " + name)

Combining text with a number

TypeError: can only concatenate str (not "int") to str

You used + to combine text with a number that isn’t in quotes. Put the number inside the quotes.

print("I am " + 12)

print("I am 12")

An extra space at the start

IndentationError: unexpected indent

There are spaces before the code on that line. Delete them so the line starts at the leftmost point.

No error, but the output looks wrong

If the output has words incorrectly spaced, add a space inside the quotes.

print("Hi" + name)

print("Hi " + name)

If the output says variable name instead of the variable, take the quotes off the variable.

print("name")

print(name)

Every coding word used in these lessons with an example.

Code
Instructions written for a computer. It follows them in order exactly from top to bottom and as written.
Python
A language for writing code. It is often regarded as the most beginner friendly language.
Run
Tell the computer to follow your code. Press the ▶ Run button to have the computer follow your code.
Output
What your program shows on the screen.
print()
Outputs a message on the screen.print("Hello, world!")
String
Text inside quotes. The quotes show where the text starts and ends."I like pizza"
Error
A message saying Python can’t follow a line of your code. It tells you which line to check.
Bug
A mistake in code. Fixing it is called debugging.
input()
Asks a question and waits for the user to type an answer.input("What is your name? ")
Variable
A labelled box that stores information so you can use it later.name = input("What is your name? ")
= (equals sign)
Stores something in a variable. It is NOT the equivalence sign you are used to, it doesn’t mean “equal to”.food = "tacos"
+ (plus sign)
Combines pieces of texts into one message."Hi " + name
Comment
A note for people that starts with #. Python see the # and skips that line when running through the code. Comments are often used to explain what lines of code does to other people reading it.# This line asks for a name
