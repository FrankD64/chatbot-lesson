Hi! Welcome to Making a Simple Chatbot.

This is a chatbot I made in Python. It asks for your name and your favourite food, and then it talks back to you. By the end of these two lessons, you’ll build one of your own.

So what is coding? Coding means writing instructions for a computer. Computers are really fast, but they only do exactly what you tell them, in the exact order you tell them. Python is a language for writing those instructions, and it’s used for games, websites, science and much more.

There are two lessons, and each one takes about 30 minutes. In Lesson 1, Making Computers Talk, you’ll use print() to show messages on the screen. In Lesson 2, Making Computers Listen, you’ll use input() and variables to ask questions and use the answers.

Every lesson works the same way. First, a short slide deck explains the idea. Then you try the code in the Python box right on the page. There’s nothing to download and no account to make. Next, you fix some broken code. Finally, you make something of your own.

You’ll probably run into some error messages along the way. Each one tells you which line to look at, and the Error Decoder beside each lesson explains what it means and how to fix it.

By the end, you’ll be able to write a print() line, use input() to save an answer in a variable, and build your own chatbot. Click Lesson 1 to get started.

How each lesson works

  1. Go through a short slide deck shown at the start.
  2. Try to run some code in the Python boxes on the page.
  3. Find and fix mistakes in buggy code.
  4. Write your own code and then explain what it does.

On the right of each lesson, there is a sidebar with the error decoder and key words page. Error decoder explains error messages and key words defines every coding term used in the lessons. On a mobile device or a small screen you can open them with the button in the bottom corner.

Press Listen at the top right of any section to hear it read aloud. The slides can be read aloud as well with the read slide buttons underneath.

You need a phone, laptop or computer with internet.
