Hi! Welcome to Your First Chatbot.

This is a chatbot I made in Python. It asks for your name and your favourite food, and then it talks back to you. By the end of these two lessons, you’ll build one of your own.

So what is coding? Coding means writing instructions for a computer. Computers are really fast, but they only do exactly what you tell them, in the exact order you tell them. Python is a language for writing those instructions, and it’s used for games, websites, science and much more.

There are two lessons, and each one takes about 40 minutes. In Lesson 1, Make the Computer Talk, you’ll use print() to show messages on the screen. In Lesson 2, Make the Computer Listen, you’ll use input() and variables to ask questions and use the answers.

Every lesson works the same way. First, a short slide deck explains the idea. Then you try the code in the Python box right on the page. There’s nothing to download and no account to make. Next, you fix some broken code. Finally, you make something of your own.

One more thing: you will see error messages. Everyone does, even professional programmers. An error doesn’t mean you’re bad at coding. It just means Python needs a small fix. If you get stuck, open the “Stuck?” hints or the Error Decoder page.

By the end, you’ll be able to write a print() line, use input() to save an answer in a variable, and build your own chatbot. Ready? Click Lesson 1 to get started.

By the end, you will be able to…

1. Make it talk

Write a print() line that shows a message, and fix one that has a mistake.

2. Make it listen

Use input() to save an answer in a variable, then print it in a message.

3. Build a chatbot

Make a short chatbot that asks two questions and uses both answers.

How each lesson works

  1. Learn it: go through a short slide deck. Use the arrow buttons, or “Show all slides” to read them all on one page.
  2. Try it: run some code in the Python box on the page.
  3. Fix it: find and fix mistakes in broken code.
  4. Make it: write your own code, then explain what it does.

Mistakes are normal. Python is picky, and one missing quote stops the whole program. That happens to everyone. Read the message, check the hint, and try again.

You need a Chromebook, laptop or tablet with internet. Python runs inside your browser, so nothing you type is sent anywhere or saved.
