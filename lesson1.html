Make the Computer Talk

In these slides, you’ll learn how to make Python show a message on the screen.

You’ll also learn the three mistakes everyone makes at first, so you can fix them fast.

Code is a list of instructions

A computer follows instructions exactly and in order, from the top line to the bottom line.

It can’t guess what you meant. If an instruction has a mistake, the computer stops and tells you.

Python is one language for writing these instructions.

Meet print()

print() shows whatever is inside the brackets.

Codeprint("Hello, world!")
OutputHello, world!

“Hello, world!” is the traditional first program that coders write.

Text needs quotes

Text in quotes is called a string. The quotes tell Python where your message starts and ends.

✓ Works
print("I like pizza")
✗ Error
print(I like pizza)

Without quotes, Python thinks I like pizza is an instruction, not a message.

One print(), one line

Each print() shows one line. Python runs them from top to bottom.

Codeprint("My favourite food is sushi.") print("My favourite game is Minecraft.") print("My favourite animal is an otter.")
OutputMy favourite food is sushi. My favourite game is Minecraft. My favourite animal is an otter.

The three most common mistakes

Missing quote
print("Hello)
Missing bracket
print("Hello"
Capital letter
Print("Hello")

One small mistake stops the whole program. That’s normal! The error message tells you which line to check.
