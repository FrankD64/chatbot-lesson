Lesson 1: Making Computers Talk

Use print() to make Python show messages on the screen. About 30 minutes.

Step 1 of 5 · 5 minutes

Key words

If you haven’t watched the intro video yet, start on the home page. Then learn these three words.

Code

Instructions written for a computer. The computer follows them in order from top to bottom and exactly as written.

print()

A Python instruction that shows a message on the screen.

String

Text inside quotes like "Hello". The quotes show where the text starts and ends.

Every key word is in the Key Words tab beside the lesson.

Read the slides as text
  1. Making Computers Talk. Lesson 1: print and strings.
  2. Code is a list of instructions. A computer follows instructions exactly and in order, from the top line to the bottom. Computers can’t guess what you meant. If a line has an error, the computer terminates the program and tells you which line has it. The picture shows three lines of code that run in order. Line 1: print Good morning. Line 2: print Time for school. Line 3: print See you later.
  3. print. Python is the language we are going to be using for this module. print shows whatever is inside the brackets as the output. The code is print, open bracket, quote, Hello, world!, quote, close bracket. The output is Hello, world!
  4. Text needs quotes. Text inside quotes is called a string. The quotes show Python where your message starts and ends. On the left, print with I like pizza inside quotes works. On the right, print with I like pizza and no quotes gives an error. Without quotes, Python reads I like pizza as instructions that it has to run, not a message. Then it will give an error because it’s not an instruction it recognizes.
  5. New lines with print. The code has three print lines: My favourite food is sushi. My favourite game is Minecraft. My favourite animal is an otter. The output shows the same three lines, in the same order. Each print only outputs one line. Every line of code is run from top to bottom in that order.
  6. Three common mistakes. First, a missing quote: print, open bracket, quote, Hello, close bracket, with no quote at the end. The fix is to add the closing quote. Second, a missing bracket: print, open bracket, quote, Hello, quote, with no closing bracket. The fix is to add the closing bracket. Third, a capital letter: Print with a capital P. The fix is to write print with a small p. Syntax errors are the easiest errors for beginners to make. If you encounter an error, the error message will tell you which line to check.
  7. Go through the lesson! Scroll down to try and run your first program. Type the code yourself, don’t copy and paste. It’s a good practice and Python may not recognize certain copied characters.
