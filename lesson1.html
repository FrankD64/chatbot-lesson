Key words

If you haven’t watched the intro video yet, start on the home page. Then learn these three words.

Code

Instructions written for a computer. The computer follows them in order, exactly as written.

print()

A Python instruction that shows a message on the screen.

String

Text inside quotes, like "Hello". The quotes show where the text starts and ends.

Every key word is in the Key Words tab beside the lesson.

Read the slides as text
  1. Making Computers Talk. Lesson 1: print and strings. In these slides you'll learn how to make Python show a message on the screen, and the three most common mistakes, so you can fix them quickly.
  2. A computer follows instructions exactly and in order, from the top line to the bottom. It can't guess what you meant, so if a line has a mistake, it stops and tells you which line. Python is one language for writing these instructions. The picture shows three lines of code that run in order: 1, 2, then 3.
  3. print shows whatever is inside the brackets on the screen. Hello, world is the traditional first program that coders write. The code print, open bracket, quote, Hello, world, quote, close bracket shows the words Hello, world! on the screen.
  4. Text inside quotes is called a string. On the left, print with I like pizza in quotes works. On the right, the same line without quotes gives an error, because Python reads I like pizza as instructions instead of a message.
  5. Each print shows one line. Three print lines give three lines of output, in the same order: favourite food, favourite game, then favourite animal.
  6. The three most common mistakes are a missing quote, a missing bracket, and print written with a capital P. Each card shows the broken line and the fixed line. One small mistake stops the whole program. The error message tells you which line to check.
  7. Your turn. Now scroll down to Try it and run your first program. Type the code yourself, because copying it can paste curly quotes, which Python can't read.
