Lesson 2: Making Computers Listen

Use input() and variables to ask questions and use the answers. About 30 minutes.

Step 1 of 4: 5 minutes

Warm up and key words

Change this line so it says hi to you, then press Run.

Two new words for this lesson:

input()

A Python instruction that asks a question and waits for the user to type an answer.

Variable

A labelled box that stores information so you can use it later.

Read the slides as text
  1. Making Computers Listen. Lesson 2: input and variables.
  2. input. The code is input, open bracket, quote, What is your name?, space, quote, close bracket. The output shows What is your name? and waits for an answer. When Python reads this line, it shows the question you typed and waits for you to type an answer and press Enter. It’s a good practice to leave a space before the closing quote so the answer doesn’t touch the question.
  3. A variable is a labelled box. The code is name equals input, What is your name? The picture shows a box labelled name, holding Sam. The equals sign means to assign the answer in the box called name. It is not the equivalence sign you are used to. If you type Sam, the box now holds Sam and you can use it later in your program.
  4. Using the variable. The code has two lines. Line 1: name equals input, What is your name? Line 2: print, quote, Hi, space, quote, plus name. The output is What is your name? Sam, then Hi Sam. The plus sign combines different pieces of text into one message. The example outputs Hi, with a space, plus whatever is in the name box.
  5. No quotes around variables. On the left, print name with no quotes prints the answer: Sam. On the right, print with name inside quotes prints the word: name. The code doesn’t need you to put quotes around variables. The computer already knows what the variable is. Putting quotes around the name of the variable makes it a string.
  6. Spaces in text output. On the left, with no space, print, quote, Hi, quote, plus name, outputs HiSam. On the right, with a space inside the quotes, print, quote, Hi, space, quote, plus name, outputs Hi Sam. The program will only add spaces if you type them out. This is a good practice to do so variables aren’t stuck next to quotes.
  7. Different variables for different questions. The code has three lines. name equals input, What is your name? food equals input, What is your favourite food? Then print Hi, plus name, plus I love, plus food, plus too! The output is: What is your name? Sam. What is your favourite food? tacos. Hi Sam! I love tacos too! Each answer should get its own variable with its own name so that you can use them separately.
  8. Go through the lesson! Scroll down to try and build your own chatbot. You can make it talk about whatever you want. Type the code yourself, don’t copy and paste. It’s a good practice and Python may not recognize certain copied characters.
Step 3 of 4: 10 minutes

Activity 3

Pick any topic for your chatbot. For example, food, games, animals, sports, music, etc.

  1. Press Run, type an answer in the box that appears and press Enter.
  2. Change the question to something else. For example, “What should I call you? ”.
  3. Add a second question about anything. Save the answer in a new variable such as game or animal.
  4. Change the print() line so your chatbot’s reply uses both answers.
  5. Explain your code. Above each line, add a comment that starts with # and says what the line below does. Python skips comments so they won’t break anything.
Stuck?

Copy the pattern of the first input() line onto a new line, change the variable name and the question, then add your new variable into the print() line with +.

You can also explain your code by recording your voice instead of writing comments.
