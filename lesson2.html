Warm-up and key words

Change this line so it says hi to you, then press Run.

Two new words for this lesson:

input()

A Python instruction that asks a question and waits for the user to type an answer.

Variable

A labelled box that stores information, like someone’s answer, so you can use it later.

Read the slides as text
  1. Making Computers Listen. Lesson 2: input and variables. In Lesson 1, your programs only talked. Now you'll make one that asks a question, remembers the answer and uses it.
  2. input shows a question and waits for you to type an answer and press Enter. Leave a space before the closing quote, so the answer doesn't touch the question.
  3. A variable is like a labelled box. This line asks for a name and stores the answer in a box labelled name. If you type Sam, the box holds Sam, and you can use it later.
  4. The plus sign joins pieces of text. print Hi plus name shows Hi, followed by whatever is stored in the name box. If the answer was Sam, it shows Hi Sam.
  5. Without quotes, print name shows what's inside the box, like Sam. With quotes around name, Python prints the word name itself.
  6. Python only adds the spaces you type. Without a space inside the quotes, the output is HiSam. With a space after Hi, it's Hi Sam.
  7. Each answer gets its own variable. This program asks for a name and a favourite food, stores them in name and food, then uses both in one message: Hi Sam! I love tacos too!
  8. Your turn. Now scroll down to Make it and build your own chatbot. You choose what it talks about.

Step 3 of 4 · 10 minutes · Activity 3

Make it: Chatbot Builder

Pick a topic for your chatbot: food, games, animals, sports, music, or your own idea.

  1. Press ▶ Run, type an answer in the box that appears, and press Enter.
  2. Change the question to something else (for example, “What should I call you? ”).
  3. Add a second question about your topic. Save the answer in a new variable, such as game or animal.
  4. Change the print() line so your chatbot’s reply uses both answers.
  5. Explain your code. Above each line, add a comment that starts with # and says what the line does. Python skips comments, so they won’t break anything.
Stuck?

Copy the pattern of the first input() line onto a new line, change the variable name and the question, then add your new variable into the print() line with +.

Seeing HiSam? Add a space inside the quotes. Seeing the word name instead of the answer? Take the quotes off the variable.

You can also explain your code by recording your voice instead of writing comments.
