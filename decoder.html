Error Decoder

Got a red error message? Find it below to see what it means and how to fix it.

Errors are normal. Every coder sees them, every day. The message tells you two useful things: which line to look at, and what kind of mistake it is.

A quote is missing

SyntaxError: unterminated string literal

What it means: your text has a quote at the start but not at the end (or the other way around).

How to fix it: make sure the text has a quote on both sides.

✗ Before
print("Hello)
✓ After
print("Hello")

A bracket is missing or extra

SyntaxError: '(' was never closed

SyntaxError: unmatched ')'

What it means: your brackets don’t match. Every ( needs exactly one ).

How to fix it: count the brackets on the line, then add or delete one so they match.

✗ Before
print("I like pizza"
✓ After
print("I like pizza")

A capital letter in print or input

NameError: name 'Print' is not defined. Did you mean: 'print'?

What it means: Python cares about capital letters. To Python, Print and print are two different words.

How to fix it: write print and input with small letters.

✗ Before
Print("Coding is fun!")
✓ After
print("Coding is fun!")

Python doesn’t know a word

NameError: name 'Hello' is not defined

What it means: Python found a word it doesn’t know. There are three common reasons:

  • You forgot the quotes around text, so Python thinks it’s an instruction.
  • You spelled a variable differently from when you made it (for example, nme instead of name).
  • You used a variable before the line that makes it.
✗ Before
print(Hello)
✓ After
print("Hello")

Curly quotes

SyntaxError: invalid character '“' (U+201C)

What it means: your code has “curly” quotes. Python only understands straight quotes ("). Curly quotes usually sneak in when you copy code from a document or slide.

How to fix it: delete the quotes and type them again with the quote key on your keyboard. The Python boxes on this site can also fix them for you.

Something is out of place

SyntaxError: invalid syntax. Perhaps you forgot a comma?

What it means: Python can’t understand how the line is put together. Often, a + is missing between two pieces you’re joining.

✗ Before
print("Hi " name)
✓ After
print("Hi " + name)

Joining text with a number

TypeError: can only concatenate str (not "int") to str

What it means: you used + to join text with a number that isn’t in quotes.

How to fix it: put the number inside the quotes as part of the text.

✗ Before
print("I am " + 12)
✓ After
print("I am 12")

An extra space at the start

IndentationError: unexpected indent

What it means: there are spaces before your code on that line.

How to fix it: delete the spaces so the line starts at the left edge, like the others.

No error, but the output looks wrong

Sometimes the code runs but doesn’t say what you wanted. Two common ones:

Output: HiSam
print("Hi" + name)

Fix: add a space inside the quotes: "Hi "

Output: name
print("name")

Fix: take the quotes off the variable: print(name)

Still stuck? Check the line number in the error, read that line one character at a time, and compare it with an example from the slides.
